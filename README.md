# house-price-prediction-ml
# House Price Prediction using Machine Learning

This project develops machine learning models to predict house prices using property features such as bedrooms, bathrooms, and living space.

## Models Used
- Linear Regression
- Multilayer Perceptron (MLP)

## Results
The Basic MLP model achieved the best performance with an R² score of approximately 0.81.

## Tools
Python, Pandas, Scikit-learn, TensorFlow
